# 🚀 ResolveAI - Complete Setup & Deployment Guide

## Step 1: Get FREE Grok API Key ⭐ (Currently Here)

### What You Need:
- A web browser
- 5 minutes of time
- NO credit card required!

### Instructions:

#### 1.1 Go to xAI Console
```
Open your browser and visit:
https://console.x.ai
```

**You should see:**
- xAI logo
- "Sign in" or "Get started" button
- Option to sign with Google/GitHub/Email

#### 1.2 Sign In (Create Account if Needed)

Click **"Sign in"** or **"Get started"**

Choose one of these options:
- ✅ **Sign in with Google** (Easiest)
- ✅ **Sign in with GitHub** (If you have GitHub)
- ✅ **Sign in with Email** (Create new account)

Follow the prompts and complete the sign-up.

**Note:** No credit card is required for Grok API!

#### 1.3 Navigate to API Keys

Once logged in:
1. Look for the left sidebar menu
2. Click on **"API Keys"** (you should see it listed)
3. Or go directly to: https://console.x.ai/keys

**You should see:**
- Current API keys (if any)
- Button to create new key

#### 1.4 Create Your API Key

1. Click **"Create New Key"** or **"Create API Key"** button
2. Give it a name: `resolveai` (or whatever you prefer)
3. Click **"Create"** or **"Generate"**

**IMPORTANT:** You will see your API key **ONLY ONCE**!

Your key will look like this:
```
xai-1234567890abcdefghijklmnop
```

#### 1.5 Copy and Save Your Key

1. **Copy** the entire API key (it starts with `xai-`)
2. **Save it somewhere safe** (text editor, notes app)
3. ✅ You'll need this in Step 3!

## ❓ Troubleshooting

### Issue: "Can't sign in"
- **Solution:** Make sure you're using correct email/password
- Try "Forgot password" if needed
- Or sign in with Google/GitHub instead

### Issue: "Can't find API Keys page"
- **Solution:** Go directly to: https://console.x.ai/keys
- Or look for "API" or "Settings" in the menu

### Issue: "API key disappeared"
- **Solution:** You only see it once! Go back to API Keys page
- You can create a new key if needed
- Delete old key and create new one
