📝 BEFORE YOU START:

1. You need a FREE Grok API key from xAI (get at console.x.ai)
2. You need OpenAI API key for embeddings only (free trial available)
3. You need MongoDB running (local or Atlas free cloud)

🚀 EASIEST WAY - AUTOMATED SETUP:

Open terminal in this folder and run:

    ./start-services.sh

This will:
✓ Create environment files
✓ Check your OpenAI API key
✓ Build FAISS index
✓ Open 3 terminals with all services

Then open: http://localhost:3000

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📖 MANUAL WAY - STEP BY STEP:

STEP 1: Setup (do once)
────────────────────────
cp ai-service/.env.example ai-service/.env
cp web-api/.env.example web-api/.env
cp client/.env.example client/.env

nano ai-service/.env
# Add: GROK_API_KEY=xai-YOUR_KEY_HERE
# Add: OPENAI_API_KEY=sk-proj-YOUR_KEY (for embeddings only)

nano web-api/.env
# Add: MONGODB_URI=mongodb://localhost:27017/resolveai

STEP 2: Start Services (3 terminals)
──────────────────────────────────────

TERMINAL 1 - AI Service:
cd ai-service
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python build_index.py
uvicorn main:app --reload --port 8000

TERMINAL 2 - API Gateway:
cd web-api
npm install
npm run dev

TERMINAL 3 - Frontend:
cd client
npm install
npm run dev

STEP 3: Open Browser
────────────────────
http://localhost:3000

❓ TROUBLESHOOTING:

"Network Error" → Services not running, check all 3 terminals
"OPENAI_API_KEY not found" → Edit ai-service/.env
"MongoDB connection failed" → Start MongoDB or use Atlas
"Port in use" → Kill process: lsof -ti:PORT | xargs kill -9

Check service health:
curl http://localhost:8000/health  (AI Service)
curl http://localhost:5000/health  (API Gateway)
