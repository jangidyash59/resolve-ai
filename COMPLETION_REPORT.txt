🔄 RAG PIPELINE (4 Agents)

1. TRIAGE AGENT
   Input: Customer ticket
   Output: Issue type + Priority
   Technology: Groq LLM

2. RETRIEVER AGENT
   Input: Ticket text → Convert to vector (Gemini)
   Output: Top 3 relevant policies (FAISS search)
   Technology: FAISS + Gemini Embeddings

3. RESOLUTION AGENT
   Input: Ticket + Retrieved policies
   Output: Customer response with citations
   Technology: Groq LLM + Policy context

4. COMPLIANCE AGENT
   Input: Generated response
   Output: Approved or Escalate
   Technology: Groq LLM (validation)
