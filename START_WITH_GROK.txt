🐛 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

Problem: "GROK_API_KEY not found"
Solution: Make sure your .env file has:
          GROK_API_KEY=xai-xxxxx (NOT xai-YOUR_KEY_HERE)

Problem: "Network Error" when submitting ticket
Solution: Make sure all 3 terminal windows are running
          Check: http://localhost:8000/health
          Check: http://localhost:5000/health

Problem: "MongoDB connection failed"
Solution: If using local MongoDB: mongod --dbpath ~/data/db
          If using Atlas: verify connection string in web-api/.env

Problem: "Module not found: sentence_transformers"
Solution: pip install sentence-transformers
