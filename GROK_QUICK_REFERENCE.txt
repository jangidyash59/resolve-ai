🚀 QUICK SETUP
════════════════════════════════════════════════════════════════════════

Step 1: Get FREE Grok API Key (2 min)
  1. Go to: https://console.x.ai
  2. Sign in (Google/GitHub/Email)
  3. Get your key (starts with xai-)

Step 2: Create .env file
  cp ai-service/.env.example ai-service/.env

Step 3: Add your Grok key
  nano ai-service/.env
  GROK_API_KEY=xai-your-actual-key-here

Step 4: Install dependencies
  pip install -r ai-service/requirements.txt
  npm install (in web-api and client)

Step 5: Start all services
  ./start-services.sh

Step 6: Open browser
  http://localhost:3000

❓ COMMON ISSUES
════════════════════════════════════════════════════════════════════════

"GROK_API_KEY not found"
  → Check ai-service/.env has your key
  → Key should start with "xai-"

"Can't connect to Grok"
  → Verify key is correct
  → Make sure no extra spaces
  → Restart AI service

"ModuleNotFoundError: sentence_transformers"
  → pip install sentence-transformers

"MongoDB connection failed"
  → Start MongoDB: mongod --dbpath ~/data/db
  → Or use MongoDB Atlas (free cloud)

"Network Error" when submitting
  → Make sure all 3 terminals are running
  → Check health endpoints
